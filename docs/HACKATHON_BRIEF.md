# Hackathon Brief — shared grounding for all plans

> Every candidate plan in `plans/` MUST align to this brief. Read it before writing a plan.

## The event

**Claude Code Build Day** — a Claude Code hackathon run by **Cerebral Valley × Anthropic**.
You build with Claude Code and demo to the Claude Code team.

- **Team size:** small (≤ 2 builders).
- **Tooling:** built with **Claude Code**; multi-agent orchestration via **Multica** is a differentiator.
- **Time:** a single intense build day (treat the buildable scope as ~1 day, demo-ready).
- **IP:** builders retain full IP.

> Note: exact build-day rules were not machine-readable from the event page; the above reflects
> the public Claude Code hackathon format. Update this section if the official rules differ.

## Judging criteria (optimize for these)

1. **Technical innovation** — a novel mechanism, not a thin GPT wrapper.
2. **Implementation quality** — it actually works in the demo; clean, real.
3. **Potential impact** — who is helped, how much, why now.

Bonus the judges (the Claude Code team) reward: a compelling **Claude Code / agentic** build
story, and a tight, surprising **2-minute live demo**.

## Seed concept (the inspiration — NOT a constraint)

From the preliminary plan *"AI life coach with Prediction"*:

> A simulated-world sandbox for benchmarking an evidence-based coaching environment. Given a user
> query, the platform understands the user's data, creates a multi-agent world, simulates the
> user's life, and predicts the effects of different choices and difficulties. Claude Code is
> central to making the simulation effective and efficient in a way previous platforms could not.
> Used a multi-agent Multica workflow aiming to outperform Interactive Machine Labs.

**The 10 plans are DISTINCT product directions** seeded from this space (evidence-based coaching,
life simulation, prediction/counterfactuals, multi-agent worlds, behavioral science, mental-health
adjacency). They are *separate ideas to compare* — not 10 versions of the same build.

## Builder context

- Domain: health / mental-health / coaching (Shanda Health Division; Lingxi).
- Strengths available: Multica multi-agent orchestration, Claude Code, evidence-based methods.
- Adjacent prior work: counselor-agent behaviour research, digital-human services.

## Hard requirements for a "good" plan

- Buildable as a demo-ready vertical slice in ~1 day by ≤2 people.
- A clear, central role for Claude Code and/or multi-agent orchestration.
- A concrete 2-minute demo that a judge can watch.
- An honest self-score against the 3 judging criteria.
